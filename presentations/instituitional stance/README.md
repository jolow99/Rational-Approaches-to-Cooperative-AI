Presentation slides on the instituitional stance paper.

Decided to try building the slides with Typst Polylux (https://polylux.dev/book/) rather than latex beamer as it compiles way quicker.

Initialized this with the Metropolis template https://github.com/polylux-typ/metropolis 

Commands used
1. typst init @preview/metropolis-polylux your-cool-project
2. Then use tinymist extension to typst preview when i have opened the slides.typ
